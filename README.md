# stock_exchange_analysis_MACD
This project implements a stock market analysis tool using the MACD (Moving Average Convergence Divergence) indicator to identify potential buy and sell signals. The tool is developed in MATLAB and is intended for educational purposes, allowing users to analyze historical stock price data and visualize trends.

Key Features:
- Calculation of MACD line and Signal line.
- Identification of buy/sell signals based on MACD crossovers.
- Visualization of stock price trends alongside MACD indicators.
- Support for user-defined time windows and parameters for MACD calculation.
